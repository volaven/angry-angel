# 모바일 UI 비교 산출물 설계

이 문서는 `previews/mobile-ui`의 비교 시안에만 적용합니다. 성인 공무원 수험생이 같은 문항을 읽고 답할 때, 문제 영역과 시연의 비중 및 손의 조작 위치가 어떻게 달라지는지 확인하는 산출물입니다.

## 공통 흐름

`타이틀(entry) → 시작 → 지문(play) → 답안 → 답 선택·잠금 → 정오답·해설 → 다음 문제`

- 타이틀과 문제풀이의 2개 화면을 3개 배치로 제공해 기본 비교 화면은 6개입니다.
- 네 검수 문항의 지문·선지·정답·해설은 모든 시안에서 동일합니다.
- 답을 고르기 전에는 해설 탭을 비활성화합니다. 답 선택 후 해설로 이동하며 같은 문항의 답을 바꿀 수 없습니다.
- 지문·답안·해설·자료는 읽기 영역 크기에 맞춰 쪽으로 나눕니다. 탭별 읽던 위치를 메모리에 보관하고, 창 크기 변경 시 해당 내용 위치를 다시 찾습니다.
- 자료 확대와 일시정지는 대화상자로 표시합니다. 세로 화면에서는 회전 안내를 표시하고 본문을 비활성화합니다.
- 비교 셸은 화면·문항·크기를 공통으로 바꾸고, 각 플레이어의 개별 진행 상태를 표시합니다. 단독 열기 주소에는 해당 시안의 현재 화면·문항을 반영합니다.

## 화면별 정체성

| 화면 | 타이틀 | 문제풀이 |
| --- | --- | --- |
| A 서고 균형형 | 왼쪽 제목·시작 버튼, 오른쪽 시연 전신 | 문제와 시연을 7 : 3 격자로 배치. 쪽 이동과 주요 행동은 문제 아래 |
| B 시험지 집중형 | 서고 위 아이보리 책 표지, 작은 시연 초상과 중앙 제목 | 시험지를 넓게 사용. 시연 초상과 짧은 반응은 상단 HUD, 하단에 조작줄 |
| C 양손 게임형 | 왼쪽 제목, 중앙 시연 전신, 오른쪽 세로 시작 버튼 | 왼쪽 쪽 이동, 중앙 문제, 오른쪽 초상·반응·주요 행동 |

타이틀의 전신/초상 사용과 문제풀이 조작 위치를 함께 바꿔 각 안을 구분합니다. 서고·캐릭터·콘텐츠·색상 체계는 공유합니다.

## 플레이어 토큰

[player.css](player.css)의 실제 CSS 변수를 기준으로 합니다. 높이 분기는 플레이어 뷰포트 높이이며 너비 기준이 아닙니다.

| 항목 | 높이 600px 이하 | 높이 601px 이상 | 높이 901px 이상 |
| --- | --- | --- | --- |
| 본문 `--body` | 22px | 28px | 32px |
| 지시문 `--instruction` | 28px | 34px | 40px |
| 주요 버튼 글자 `--action` | 20px | 24px | 26px |
| 주요 버튼·선지 최소 높이 `--touch` | 72px | 88px | 88px |
| 탭·일반 조작 최소 높이 `--control` | 52px | 60px | 60px |
| 내부 간격 `--gap` | 8px | 12px | 12px |
| HUD 높이 `--hud` | 58px | 70px | 70px |

본문은 행간 1.6, 지시문은 1.4를 사용합니다. 보조 정보·말풍선·쪽 수에는 별도 크기를 적용하므로 본문 토큰이 화면의 모든 글자 크기를 뜻하지는 않습니다. 비교 셸의 조작 크기는 [compare.css](compare.css)에 따로 정의합니다.

| 색상 | 값 | 역할 |
| --- | --- | --- |
| 남색 `--navy` | `#202c40` | HUD, 선택된 탭, 시연 말풍선 |
| 아이보리 `--paper` | `#fffcf4` | 시험지, 버튼, 대화상자 |
| 본문색 `--ink` | `#252e3c` | 지문과 선지 |
| 버건디 `--wine` | `#782d44` | 주요 행동, B의 활성 탭 |
| 금색 `--gold` | `#b49a6c` | 시험지·캐릭터 영역의 경계 |
| 선색 `--line` | `#c9bea9` | 조작과 영역 구분 |

정오답은 선지의 색상과 함께 **정답**, **내 답 · 오답** 문구로 표시합니다. 시연의 전신과 B·C의 초상에는 같은 0.55초 등장 효과를 적용합니다. 키보드 포커스 윤곽선을 제공하며, `prefers-reduced-motion: reduce`에서는 애니메이션과 전환을 끕니다.

## 기존 자산 재사용

새 이미지·음성은 만들지 않았습니다. [ASSETS.json](ASSETS.json)에 각 복사본의 원본 경로, 바이트 수, SHA-256을 기록합니다.

- `public/characters/runtime/`의 `idle`, `question`, `correct`, `sigh` 시연 이미지를 전신 또는 초상으로 사용합니다.
- `public/ui-v3/library.webp`를 타이틀의 서고 배경으로 사용합니다.
- `public/fonts/NotoSansKR.ttf`를 로컬 글꼴로 사용합니다.
- 기존 시험 원문 네 장과 국어 12번의 자료 이미지를 사용합니다. 영어 밑줄은 픽스처의 표식으로 렌더링합니다.

[fixtures.js](fixtures.js), 자산, 일반 스크립트를 한 폴더에서 로딩해 `file://`와 HTTP 모두에서 실행합니다. 플레이어는 비교용 메모리 상태만 가지며 실제 앱 저장소·진도·오프라인 캐시와 연결하지 않습니다.
