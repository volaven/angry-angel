최초 버튼 `button.png`는 바깥 투명 여백이 있어 화면에서 프레임이 눌려 보였다. 전체 캔버스를 채우도록 내장 이미지 도구로 `button-v2.png`를 새로 제작했다. 첫 원본은 보존하고 앱에는 v2만 사용한다.

PNG 원본은 이 폴더, 앱용 WebP는 `public/ui-v3`에 보관한다. 변환은 크기 조정과 포맷 변환만 수행한다. 원본/런타임 체크섬, 해상도, 알파 범위, 바이트 수와 사용 경로는 `manifest.json`에서 자동 생성한다.
