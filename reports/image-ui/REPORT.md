# A안 이미지 UI 적용

2026-11-04 · 버튼·탭·답안·상단·메뉴 카드·문제 패널·관리 패널·시연 말풍선을 새 이미지 UI로 교체했다. A안의 타이틀 60:40, 문제 70:30, 큰 글씨, 화면 페이지 방식은 유지한다.

## 제작·동작

- 내장 이미지 생성 도구로 버건디 주 버튼, 아이보리 보조 버튼, 문서 패널, 남색 대화 패널을 각각 제작했다. [자산과 전체 프롬프트](../../assets/ui-v6/README.md).
- 9분할 고정 모서리를 사용하므로 작은 탭과 넓은 패널에서 모서리 장식이 찌그러지지 않는다. 그림 위에 실제 글자와 입력 영역을 둔다.
- 선택·정답·오답·비활성·키보드 포커스를 구분한다. 정답·오답 문구와 기존 답안 잠금을 유지한다. 이미지 실패에도 실제 바탕색·버튼·글자는 남는다.
- 장식에 닿던 메뉴 아래쪽 설명은 안쪽 여백을 늘리고, 작은 화면의 과목명은 단어 단위로 줄을 바꾼다.
- 기존 은발 시연·연출·의상·문항·답안·학습 기록·저장 키를 변경하지 않았다. 검수 완료 80문항과 잠금 120문항을 유지한다.

## 검증

- [이미지 UI 검사](audit.json): 4개 가로 규격, 4개 대표 문항, 타이틀·메뉴·과목·설정, 정답·오답·답 잠금·새로고침과 세로 회전 안내. 4개 이미지의 실제 CSS 사용과 HTTP 로딩을 검사했다.
- [전체 배치·문항 검사](full-audit.json): 12개 화면 크기, 80문항×3개 크기의 지문·답안·해설. 내용 누락·중복·스크롤·잘림·실행 오류 검사 통과.
- [마지막 메뉴 여백 확인](home-audit.json): 여백 및 단어 줄바꿈 조정 후 4개 가로 규격 재확인.
- [오프라인 검사](offline-audit.json): 네 UI 이미지의 캐시 SHA-256 대조, 오프라인 답안 복구, 이미지 요청 실패 상태에서도 답 선택·해설 확인.
- 기존 자동 검사 17개, TypeScript, Vite 웹·오프라인 빌드 통과. 새 이미지 4개는 총 309,840바이트다.

이전 A안 화면은 [이전 기록](../selected-a/IMPLEMENTATION.md), 이번 캡처는 이 폴더에 있다. 실제 휴대전화·태블릿은 검사하지 않았으며 데스크톱 Edge의 화면 크기 에뮬레이션 결과다. APK는 제작하지 않았다.
