# 선택 시안 A 메인 앱 반영

2026-11-03 사용자가 선택한 **A 서고 균형형**을 메인 앱의 타이틀과 문제풀이에 반영했다. [A·B·C 비교물](../../previews/mobile-ui/README.md)은 독립 보관본으로 유지한다.

## 반영 범위

- `src/main.ts`: 전체 높이의 60 : 40 타이틀, 국가직 9급·일반행정 안내·제목·짧은 소개·문제 풀기 버튼. 버튼은 학습 메뉴를 열며 기존 실행을 유지한다. 문제 화면은 이름과 짧은 반응 중심의 말풍선을 사용한다.
- `src/game-ui.css`: A의 색상·크기 토큰, 평평한 아이보리 시험지, 문제 70 : 시연 30, 시험지 아래 쪽 이동과 주요 행동. 큰 본문과 조작 크기는 [디자인 기준](../../DESIGN.md)을 따른다.
- `src/paged-reader.ts`: 접근 가능한 이전·다음 쪽 조작에 SVG 화살표를 사용한다.
- 지속적인 `CharacterDirector`, 기존 캐릭터·배경·과목 그림, 호감도 기록·의상 해금, 저장 키와 학습·복구 모델을 유지한다. 문제 화면에서 호감도 표시를 줄였으며 음성 제거 상태와 검수 완료 80문항·잠금 120문항을 유지한다.

## 화면 상태 지도

`entry → 문제 풀기 → home → subjects / 오늘의 과제 / 오답 복습 → play`

`play: 지문 ↔ 답안 → 답 선택·잠금 → 정오답·해설 → 다음 문항 → result`

자료 탭·자료 확대와 탭별 쪽 이동을 제공한다. `play → pause → 학습 복귀 / home / settings`로 이동하고 답안과 읽던 위치를 복구한다. 재실행과 회전 시 실행을 유지한다. 기존 모의고사 선택 화면·문항 탭·제출 흐름과 실제 종료 시각은 유지하며, 미검수 모의고사의 시작은 잠겨 있다.

기존 관리 화면은 폐기물 보관소 `wrong`, 기록실·의상 `wardrobe`, 학습 기록 `history`, 설정·기록 내보내기 `settings`, 원문 검수 `sources`, 결과에서 해설 다시 보기 `inspect`다.
