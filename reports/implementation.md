# 구현 기록

화면 흐름: 서고(시작/이어하기) → 과목·연도 선택 → 문제 → 판정·해설 → 결과 → 서고. 보관소는 별도 복습 실행이며 기록·설정·의상 화면을 제공한다. 설정과 뒤로 가기는 입력 잠금 중에도 사용한다.

재사용 기반: Mathheroes Vite·TypeScript 구성, 세션 단위 음성 취소/일시정지 구조, JSON 저장 복원·오프라인 정적 캐시 패턴. 원본 프로젝트는 수정하지 않는다. 저장 키는 siyeon-exam.v1, 캐시는 siyeon-exam 전용이다.

기출 원문·최종 정답·해설 검증은 각 문항 검수 상태로 관리한다. 미검수 문항을 출제 완료로 간주하지 않는다. 실제 기기 푸시 검증은 HTTPS 운영 환경이 필요하다.
