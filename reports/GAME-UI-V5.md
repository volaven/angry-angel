# 큰 조작부와 시연 2D 연출 — 검증 보고서

검증일: 2026-11-03. Vite·TypeScript 웹 유지. APK 생성 없음.

## 구현

- 높이 ≤600 / 601–900 / ≥901px에서 본문 **22 / 28 / 32px**, 지시문 **28 / 34 / 40px**. 주요 조작 **72 / 88 / 88px**, 탭·페이지 **52 / 60 / 60px**.
- 상단 한 줄에 과목·연도·문항·진행·모의고사 시계. 문제 패널 70%, 시연 30%. 하단 페이지·행동 조작은 정상 문서 흐름의 한 줄로 배치.
- 기존 실측 페이지 분할과 원본 읽기 위치 유지. 영문 장식 소제목 제거, 프레임과 버튼 그림자 정돈.
- 지속 CharacterDirector/Canvas 한 개, 12개 상태. 몸통·머리·눈 감은 머리·전경 팔을 독립 합성. 세 의상은 공통 몸통을 사용하여 표정마다 비율이 바뀌지 않도록 등록.
- 등장 600ms, 판정 동작 약 1초, 낮은 빈도의 눈 깜빡임과 작은 머리·팔 움직임. 정답 입자는 손 주변에만 표시.
- 탭·쪽 이동·회전으로 연출 재시작 안 함. 실행/문항/이벤트를 세션 내 중복 방지. 회전·일시정지·비활성에서 정지. 움직임 줄이기에서는 정적 조립 포즈. 이미지 실패 시 원래 정적 포즈.
- 음성 제거, 80문항 출제 가능 / 120문항 잠금, 문항 ID·저장·오답·호감도·의상 규칙 유지.

### 성능 범위

데스크톱 Edge에서 80회 탭 변경 후 Canvas는 1개. GC 후 JS heap 증가 333,824바이트. CPU 4배 느리게 설정한 브라우저 rAF는 약 60.1회/초이며 캐릭터 그림은 약 30회/초로 제한한다. 이는 실제 저사양 태블릿의 FPS/배터리/메모리 보증이 아니다. 이미지 디코딩 메모리는 JS heap 수치에 포함되지 않는다.

### 용량

새 레이어 앱용 파일 20개, 7.89MiB. 오프라인 빌드 305파일, 55.27MiB. 생성 PNG 원본과 불채택 atlas 셀은 개발용 보관소에 두고 앱은 등록된 WebP만 포함한다.

## 검증 범위와 남은 외부 확인

- 브라우저: Windows의 headless Edge, 서로 분리된 테스트 저장소. 실제 사용자 기록 변경 없음.
- 실제 Android/iOS 기기의 터치, 발열·배터리, 설치 PWA 동작은 이번 브라우저 검사로 확인하지 않았다.
- 콘텐츠 검수 대기 120문항과 실제 푸시 서버/기기 수신은 기존 미완료 범위로 유지한다.
- Vite의 기존 단일 청크 크기 경고가 남아 있다. 빌드 오류는 없으며 문제은행 분할 로드는 별도 최적화 대상이다.
